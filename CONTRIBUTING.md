# Contributing

Thanks for your interest in proTES! Bug reports, feature requests,
discussions, documentation and code are all welcome. The project follows the
[contributor guide of ELIXIR
On-Cloud](https://elixir-cloud-aai.github.io/contribute/); in short:

- Follow our [code of conduct](CODE_OF_CONDUCT.md).
- Report vulnerabilities privately, as described in the [security
  policy](SECURITY.md).
- Work on [issues](https://github.com/elixir-cloud-aai/proTES/issues): open
  or find one and agree on the approach before you change code.
- Branch off `dev` and open a pull request against `dev` (not `main`, which
  only holds releases) that closes the issue; it is squash-merged once the
  checks pass and it has been reviewed.
- Title pull requests as [Conventional
  Commits](https://www.conventionalcommits.org/)
  (`<type>[(<scope>)][!]: <description>`, at most 50 characters).
- Keep the checks green and the coverage at 100%, with docstrings, type hints
  and the pre-commit hooks; update the documentation.

**See [Contributing in the
documentation](https://protes.readthedocs.io/en/latest/contributing/) for the
details**, including the Python guidelines.
