# Contributing

This project is a community effort and lives off your contributions, be it
bug reports, feature requests, discussions, documentation or code. See
[`CONTRIBUTING.md`](https://github.com/elixir-cloud-aai/proTES/blob/dev/CONTRIBUTING.md)
for how to contribute, and mind the [code of
conduct](https://github.com/elixir-cloud-aai/proTES/blob/dev/CODE_OF_CONDUCT.md)
in all interactions with the community.
